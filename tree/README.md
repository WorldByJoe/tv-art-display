# A tree grown from its carbon budget

Not a fractal and not an L-system. Every shoot is paid for out of what the leaves earned that season, against the cost of building and maintaining the wood already standing. The shape is what is left over.

## Running it

Open `index.html` in a browser. That is the whole of it - one file, no build,
no server, no keys. It is written for a 4K screen and scales down.

Press `i` for the parameters it is running, and the arrows appear if you move
a pointer.

## What it is doing

- Growth rate is an OUTPUT here, never a setting. Where the model grows too slowly the answer is a missing mechanism, not a coefficient to raise.
