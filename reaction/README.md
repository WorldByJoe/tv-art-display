# Two chemicals, and every animal pattern

A Gray-Scott reaction-diffusion system: one chemical feeds, another consumes it and reproduces, both spread at different rates. Change two numbers and the same equations give spots, stripes, mazes, waves, or dividing cells - which is Turing's 1952 answer to how a uniform embryo becomes a patterned animal.

## Running it

Open `index.html` in a browser. That is the whole of it - one file, no build,
no server, no keys. It is written for a 4K screen and scales down.

Press `i` for the parameters it is running, and the arrows appear if you move
a pointer.

## What it is doing

- Nothing in the model knows what a stripe is. The pattern is a standing instability, and which one you get is set entirely by the feed and kill rates.
