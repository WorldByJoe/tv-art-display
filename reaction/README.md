# Turing's answer to how a uniform embryo gets a pattern

A Gray-Scott reaction-diffusion system: one chemical is fed in, another consumes it and copies itself, and the two spread at different rates. Change two numbers and the same equations give spots, stripes, mazes, waves or a moving front - which is Turing's 1952 answer to how a uniform embryo becomes a patterned animal.

## Running it

Open `index.html` in a browser. That is the whole of it - one file, no build,
no server, no keys. It is written for a 4K screen and scales down.

Press `i` for the parameters it is running, and the arrows appear if you move
a pointer. A standalone copy starts itself again when a run ends; add
`?pin` to the URL to keep the current run going instead.

## What it is doing

- Only the feed rate and the kill rate change between patterns. Everything else is held: U diffuses twice as fast as V, the grid is the same, the seeding is the same. Two numbers is the whole difference between a leopard and a zebra.
- The presets were not inherited and they were not chosen by eye. The textbook set was thrown out and this one found by measurement - each candidate run out and scored on the size of its features and how much it was still moving, then the survivors stratified so that consecutive patterns do not look alike. One regime was cut after the fact: at the length the wall actually shows it, dividing cells were indistinguishable from spots.
- A visit is two patterns, forty-six seconds each, and that is deliberately few. The interesting part of a Gray-Scott run is the first minute, while the front is still advancing into fresh ground.
- The page says one sentence per pattern as it starts, and nothing else. There is no permanent caption.
