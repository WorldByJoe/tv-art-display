# A balance, hung

A mobile in which every rod really balances - mass times distance, the lever law - and every animal is cut the same size, so the picture tells you nothing about how heavy anything is. The only place mass lives is the geometry: a heavy animal is pinned hard against its pivot while a light one rides far out on a long arm.

## Running it

Open `index.html` in a browser. That is the whole of it - one file, no build,
no server, no keys. It is written for a 4K screen and scales down.

Press `i` for the parameters it is running, and the arrows appear if you move
a pointer. A standalone copy starts itself again when a run ends; add
`?pin` to the URL to keep the current run going instead.

## What it is doing

- Seven mammals are drawn from a stable of twenty-eight spanning eight orders of magnitude, from a two-gram Etruscan shrew to a hundred-and-fifty tonne blue whale. They are not drawn at random: a mobile is built lightest-first and each animal hangs against the SUM of everything already on it, so the draw is built the same way - seven picked blindly give a median worst joint of 100:1 and, one time in ten, something past 1500:1.
- Every animal carries the same AREA OF INK, not the same bounding box. Fitting each into one square gave the blue whale a third of the ink of a Labrador, so the largest animal alive read as one of the smallest things on screen.
- The rods bend by beam theory - a tip-loaded cantilever, flat where it leaves the pivot and steepening all the way out. Because the rod balances, the drop goes as the SQUARE of the arm, so on a 33:1 joint the long arm bends about eleven hundred times as far as the stubby one.
- Gusts arrive from a random bearing every few seconds. What turns a rod is the DIFFERENCE in wind moment between its two arms, summed board by board with each at its own facing; a board side-on catches nothing. Everything also swings as a pendulum on its own thread, and a swung pendulum hangs higher, which feeds the horizontal motion back into the vertical.
- Some evenings it hangs small sailboats instead, on a perfect binary tree so that all of them end in one plane.
