# Five works from a museum, chosen at random

Five public-domain works drawn live from the Art Institute of Chicago's open collection, one at a time, each with what the museum knows about it and a paragraph on the artist from Wikipedia. Nothing is stored in the page: every visit is a different five, out of a collection that runs to tens of thousands.

## Running it

Open `index.html` in a browser. One file, no build, no server, no keys - but this piece
fetches what it shows while it runs, so it does need a network. It is written for a 4K
screen and scales down.

Press `i` for the parameters it is running, and the arrows appear if you move
a pointer. A standalone copy starts itself again when a run ends; add
`?pin` to the URL to keep the current run going instead.

## What it is doing

- The picture is fetched full-size from the museum's IIIF image server and the record from its public API - no key, no account, no scraping. The page holds no images and no catalogue of its own.
- The rail beside the picture is trimmed to fit rather than scrolled or shrunk: whole sentences are dropped until nothing overflows, and the artist paragraph gives way before the caption does. A line that would overflow is silently absent, which is the only honest option on a screen nobody is standing at.
- Because it draws everything at run time, this page is blank without a network - there is no cached fallback, and none would be worth having when the pictures are the point.
